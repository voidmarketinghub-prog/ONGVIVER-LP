# LP Campanha Tijolinho — ONG Viver

Landing page da campanha Construtores da Esperança (Tijolinho) da ONG Viver.

## Estrutura

- index.html — página completa (HTML, CSS e JS em um único arquivo)
- - assets/ — imagens, vídeo e favicon
 
  - ## Hospedagem
 
  - Site 100% estático, sem build, dependências ou back-end. Basta servir o conteúdo desta pasta na raiz do domínio (Apache, Nginx, cPanel, Vercel, Netlify, Cloudflare Pages etc.).
 
  - - Fontes carregadas via Google Fonts (requer acesso a fonts.googleapis.com).
    - - Feed do Instagram usa o embed oficial (instagram.com/ongviver/embed).
     
      - ## Pendências de conteúdo
     
      - - Botão "Adquirir meu tijolinho" aponta para o WhatsApp oficial da Viver. Substituir pelo link do checkout quando definido (marcado com TODO no index.html).
        - - CNPJ da instituição no rodapé.
